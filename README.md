# 🌙 잠코치 (SleepCoach)

> **청소년 절반이 자기가 잠이 부족한 줄도 모른다. 그걸 데이터로 비춰주고, 습관을 바꾸게 돕는 AI 도우미.**

한국 청소년의 수면 부족과 스마트폰 과의존 문제를 해결하기 위해, 스스로 자신의 수면 및 스마트폰 사용 패턴을 인지하고 작은 습관부터 바꿀 수 있도록 돕는 웹 애플리케이션입니다.

## ✨ 주요 기능

*   **⏱️ 데일리 기록 (30초 컷)**
    *   어제 잔 시각, 오늘 일어난 시각, 자기 전 스마트폰 사용 시간, 오늘 컨디션을 간단하게 기록합니다.
    *   입력의 번거로움을 최소화하기 위해 직관적인 UI(시간 선택, 슬라이더, 이모지)를 적용했습니다.
*   **🧠 AI 패턴 분석**
    *   3일 이상의 기록이 쌓이면 Gemini API를 활용하여 사용자의 수면 패턴을 분석합니다.
    *   "평균 수면 시간 부족", "취침 시각 불규칙", "스마트폰 사용에 따른 컨디션 저하" 등 객관적인 데이터 기반의 인사이트를 친구 같은 따뜻한 말투로 제공합니다.
*   **🎯 오늘의 미션**
    *   가장 시급하게 개선해야 할 패턴을 파악하여 매일 1개의 맞춤형 미션(예: "오늘은 30분만 일찍 불 끄기", "11시 전에 폰 충전기에 꽂아두기")을 추천합니다.

## 🛠️ 기술 스택

*   **Frontend**: HTML5, CSS3 (Vanilla), JavaScript (ES6+)
*   **AI / API**: Google Gemini API (자연어 코멘트 생성)
*   **Data Storage**: Web LocalStorage (서버 없이 브라우저에 안전하게 저장)

## 🚀 시작하기

이 프로젝트는 별도의 서버나 데이터베이스 없이 브라우저 환경에서 동작합니다.

1.  저장소를 클론하거나 다운로드합니다.
2.  `index.html` 파일을 웹 브라우저에서 엽니다.
3.  우측 상단의 **설정(톱니바퀴) 아이콘**을 클릭하고 **API 설정**을 눌러 본인의 Gemini API 키를 입력합니다.
    *   API 키는 브라우저 LocalStorage에만 저장되며 외부로 전송되지 않습니다.
4.  기록 탭에서 오늘 하루의 수면/스마트폰 데이터를 입력해 보세요!
